# ✂️ BizBook 2.0 — CRM & Онлайн-запись для Барбершопа

**BizBook 2.0** — это современная ERP/CRM-система и сервис онлайн-записи для автоматизации бизнеса в сфере услуг (ориентировано на барбершопы и салоны красоты). Проект построен на архитектуре с поддержкой **мультитенантности (Multi-tenancy)**, что позволяет изолировать данные разных брендов в рамках одной кодовой базы.

## 🚀 Основные возможности

* **Мультитенантность:** Фильтрация данных и контекста запросов по заголовку `X-Tenant-Slug` (например, `elite-barbers`).
* **Интерактивная карта:** Выбор филиала барбершопа прямо на карте с использованием Leaflet / OpenStreetMap.
* **Пошаговый мастер записи (Booking Wizard):** Интуитивный UI для выбора филиала, мастера, услуги, даты и свободного тайм-слота.
* **Интеграция с Telegram:** Встроенный Telegram-бот, работающий в режиме реального времени (Polling) для уведомлений о записях.
* **Панель Администратора:** Авторизация, просмотр аналитики и управление расписанием мастеров.

---

## 🛠️ Стек технологий

* **Frontend:** React.js, Vite, TailwindCSS, React Router, Leaflet (Карты)
* **Backend:** Node.js, Express.js, MongoDB (Mongoose), Telegram Bot API
* **Деплой / Хостинг:** Vercel (Фронтенд), Render (Бэкенд), MongoDB Atlas (База данных)
